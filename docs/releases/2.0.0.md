# 2.0.0 - Python-native metaWRAP

The first release reproduces metaWRAP 1.x: same algorithms, same external tools, same thresholds,
same results. This lets an existing analysis be migrated and reproduced before anything changes
underneath it, and golden tests still pin the equivalence.

## What's new

- `metawrap2 <module>`, one Python module per module, no Bash, Perl or R.
- Per-module conda environments holding only that module's tools, so each resolves quickly and
  independently.
- The command each module runs is a visible, editable template at the top of the module file, and
  any surfaced constant can be overridden in `~/.metawrap2/config.toml`.
- Modern packaging: a wheel, pinned dependencies, and an installable entry point.

## Defaults that moved

None. Every threshold, tool and flag is metaWRAP 1.x's.

## Known gaps at this version

No cohort support, no measurement harness, no chimerism detection; all three arrive in 2.1.0.
