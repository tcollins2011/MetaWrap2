# 2.1.0 - defaults chosen by measurement, and chimerism detection

This release adds the benchmark harness, moves the first default on its output, and turns on a
check the marker-gene scorers cannot do.

## What's new

- **`metawrap2 benchmark list|fetch|run|score`.** Comparisons are declared as data in
  `benchmarks/configurations.toml`, results land in a committed TSV, and cost is CPU-hours measured
  by reaping the child process. A moved default arrives in review next to its numbers. `fetch` is
  checksum-verified and refuses to cross a disk ceiling.
- **Chimerism detection on by default.** GUNC annotates bins whose marker genes look clean but
  whose sequence comes from two organisms, which CheckM cannot see.
- **Cohorts as a first-class input.** `coverage` builds one cross-sample depth table from N
  alignments instead of N², and `dereplicate` collapses per-sample bins into a catalogue of
  organisms.
- **Three learned binners**: SemiBin2, VAMB and COMEBin, GPU-capable, in one opt-in environment.
- **`metawrap2 doctor`** probes every module's environment, software and databases and prints an
  installed / missing / broken map; `--fix` rebuilds what is broken.

## Defaults that moved, with the measurement

| Default | Was | Now | Why |
|---|---|---|---|
| binning tier | metaBAT2 + MaxBin2 | metaBAT2 + SemiBin2 | 53 clean HQ MAGs against metaWRAP 1's 48, for 43.8 CPU-hours against 52.5: the first configuration to beat the baseline on both axes. The old tier returned 41 for 13.8 and was chosen on a quality-per-cost ratio |
| depth identity floor | none (0%) | 90% | reads from relatives inflate coverage, and the binner reads coverage |
| GUNC | not run | on | see above |
| aligner for depth | bwa | minimap2 | Spearman 0.984 on contig depth for 1.37 CPU-hours against 7.77 |

The tier change means a plain run needs `metawrap2-learned`, about 1.5 GB of pytorch.
`--preset fast` reproduces the old behaviour.

## Known gaps at this version

`--preset slow` is COMEBin alone, based on a gold-assembly tie that 2.1.1 overturns with an
end-to-end measurement. No functional annotation beyond a Prokka wrapper.
