# 2.1.0 - benchmarked defaults and chimera detection

Adds the benchmark harness, the first default changed on its results, and GUNC chimerism checks.

## What's new

- **`metawrap2 benchmark list|fetch|run|score`.** Comparisons are declared in
  `benchmarks/configurations.toml` and results are written to a committed TSV. Cost is CPU-hours,
  measured by reaping the child process. A change to a default is reviewed together with its
  numbers. `fetch` verifies checksums and stops at a disk ceiling.
- **Chimerism detection on by default.** GUNC flags bins whose marker genes look clean but whose
  sequence comes from two organisms. CheckM does not detect this.
- **Cohort input.** `coverage` builds one cross-sample depth table from N alignments instead of N².
  `dereplicate` collapses per-sample bins into a catalogue of organisms.
- **Three learned binners**: SemiBin2, VAMB and COMEBin, with GPU support, in one optional
  environment.
- **`metawrap2 doctor`** checks every module's environment, software and databases and reports
  each as installed, missing or broken. `--fix` rebuilds broken ones.

## Changed defaults

| Default | Was | Now | Why |
|---|---|---|---|
| binning tier | metaBAT2 + MaxBin2 | metaBAT2 + SemiBin2 | 53 clean HQ MAGs for 43.8 CPU-hours, against metaWRAP 1's 48 for 52.5; the first configuration better on both. The old tier returned 41 for 13.8 and had been chosen on quality per CPU-hour |
| depth identity floor | none (0%) | 90% | reads from related genomes inflate the coverage the binners use |
| GUNC | not run | on | detects chimeric bins (above) |
| aligner for depth | bwa | minimap2 | Spearman 0.984 on contig depth, 1.37 CPU-hours against 7.77 |

The new tier requires `metawrap2-learned` (about 1.5 GB, mostly pytorch). `--preset fast` gives
the old behaviour.

## Known gaps at this version

`--preset slow` is COMEBin alone, based on a tie on the gold assembly. 2.1.1 changed it after an
end-to-end measurement. Functional annotation is limited to a Prokka wrapper.
