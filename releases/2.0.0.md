# 2.0.0 - Python-native metaWRAP

A port of metaWRAP 1.x with the same algorithms, external tools, thresholds and results. Existing
analyses can be migrated and reproduced; golden tests check the equivalence.

## What's new

- `metawrap2 <module>`, one Python module per module, no Bash, Perl or R.
- Per-module conda environments holding only that module's tools, each resolved independently.
- The command each module runs is an editable template at the top of the module file. Surfaced
  constants can be overridden in `~/.metawrap2/config.toml`.
- Packaging: a wheel, pinned dependencies and an installable entry point.

## Changed defaults

None. All thresholds, tools and flags are metaWRAP 1.x's.

## Known gaps at this version

No cohort support, measurement harness or chimerism detection. All three were added in 2.1.0.
