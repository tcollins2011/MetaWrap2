# 2.0.1 - pipeline driver and verified resume

Infrastructure only; no scientific behaviour changed.

## What's new

- **`metawrap2 run <sheet|directory>`** runs a whole study from a TOML or YAML sample sheet. It
  manages the intermediate layout and the steps in between, which the tutorial previously did with
  `mkdir`/`mv`/`cat`.
- **Verified `--resume`.** A step is skipped only if it completed, its outputs are present and
  non-empty, and none of its inputs has changed. `metawrap2 status` shows what a resume would do.
- **Run history.** `metawrap2 history` records every run started on the machine, stored outside
  the output directories. `--diff` compares two runs.
- **Bin naming**: `bin_001.fasta`, with statistics tables as `*.stats.tsv`.
- **One-command install**: `metawrap2 quickstart` builds the environments and verifies them.

## Changed defaults

None.

## Known issue

`install-env` could not create three environments (bakta, checkm2, gtdbtk) under any name, because
it read only one of the four registries that map names to environments. Fixed in 2.1.2. On 2.0.x, create these three with
`mamba env create -f <envs>/<name>.yaml`. See [2.1.2](2.1.2.md#9-correctness-fixes).
